# Screen Monitor（屏幕监视）

本机是用户远程办公时的工作机。本技能配合 `screenshot` / `list_windows` 工具，
让用户通过手机查看工作机屏幕。

## 何时使用

- 用户说「看看屏幕 / 电脑上现在什么情况 / 截个图 / 看一下桌面」；
- 用户询问某个窗口、应用、文档、页面的显示状态（先 `list_windows` 找窗口）；
- 任务执行涉及界面（如等待某个界面元素出现、确认弹窗），视觉确认有帮助时，
  可以主动截图确认；
- 用户想监视后台任务、长时间运行的进程的界面状态。

## 使用步骤

1. **桌面全屏**：直接 `screenshot`（reason 写清楚截图目的，供用户审批）。
2. **特定窗口**：
   - 先 `list_windows` 找到目标窗口的标题或 hwnd（优先选 `visible: true` 且
     `minimized: false` 的窗口）；
   - 再 `screenshot(window="标题子串")` 或 `screenshot(hwnd="句柄")`。
3. **窗口被最小化/隐藏**：截图会失败并返回原因，此时告诉用户，并询问是
   改为截桌面还是由用户在工作机恢复窗口。
4. **标题有歧义**（多个窗口匹配）：用返回的 hwnd 精确定位。

## 看图与汇报

- 截图返回后，你会看到图片内容（仅当当前模型支持图片输入）。向用户
  **描述画面要点**：打开的窗口、标题栏、明显状态（如进度条、错误弹窗、
  空屏/锁屏）。
- 用户没细问时，描述控制在 2-4 句，别逐像素复述。
- 敏感信息（密码输入框、聊天内容等）不要主动复述细节，只描述界面结构。

## 模型不支持图片时（重要）

当前默认模型（DeepSeek 官方适配器）为文本-only。工具会自动检测并降级：
`screenshot` 正常调用即可（无需手动传 `include_image: false`），结果里会带
`note` 字段说明图片未嵌入。此时：

1. 截图仍会成功并归档；
2. 如实告诉用户：图片已保存，**让用户打开网关画廊查看**
   `http://<电脑IP>:8080/shots`（手机浏览器登录后即可，每 8 秒自动刷新，
   相当于实时监视画面）；
3. 你无法看到画面，不要猜测屏幕内容；可以结合 `list_windows` 的结果
   描述有哪些窗口在运行。

## 参数建议

- 手机屏幕小：默认 PNG 即可；网络差或图很大时用 `format: "jpeg"`。
- 需要看清文字时不要缩放（`scale` 缺省由系统限制保证）。
- `include_image: false` 可强制只记录元数据（此时你看不到画面，只能拿到
  元数据，应如实告知用户）。

## 隐私与审批

截图是敏感操作，每次调用都会在 GUI 弹出审批。**不要**在用户未要求或
场景明显不需要时主动截图；用户拒绝审批时尊重结果，不要反复重试。
